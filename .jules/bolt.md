## 2025-05-14 - Parallelize Image Analysis in Survey Workflow
**Learning:** The `handleAnalyze` function was processing multiple survey images sequentially using an `await` inside a `for...of` loop. Since each image requires an independent Gemini AI analysis (high latency) and a database save (I/O latency), this created a linear bottleneck ($O(N)$ latency). Parallelizing these operations with `Promise.all` allows the browser and backend to handle multiple requests concurrently, reducing total wait time to approximately the latency of a single image ($O(1)$ latency improvement for the batch).
**Action:** Always look for sequential `await` calls in loops that process independent data batches, especially when dealing with external API calls or database operations, and replace them with `Promise.all` or similar concurrency patterns.
