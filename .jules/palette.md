## 2025-05-15 - Accessibility and Interaction Polish
**Learning:** Empty states in primary views (like Survey History) should always provide a clear path forward (e.g., a "Start New Survey" button) to prevent "dead ends" in the user experience.
**Action:** Always check for empty states in primary data views and ensure they include a relevant call-to-action (CTA).

**Learning:** When using icon-only buttons, `aria-label` is mandatory to provide context for screen reader users.
**Action:** Audit all icon-only buttons and add descriptive `aria-label` attributes.
