## 2025-05-14 - Accessible Lists and Empty States
**Learning:** Interactive list items implemented as `div` elements are inaccessible to keyboard users and screen readers. Additionally, empty states without a Call-to-Action (CTA) create dead ends in the user flow.
**Action:** Always use semantic `<button>` elements for interactive list items with explicit `focus-visible` styles. Ensure every empty state provides a clear path forward with a high-visibility CTA.
